# PNG finales de cooking

Guardar aquí el material terminado; no colocar números de timer ni items
de ejemplo dentro del fondo final, porque esos elementos se dibujan por código.

- `oven/`: fondo limpio del horno y sus estados (calor, agua, etc.).
- `mode-menu/`: PNG del mini menú Cook / Arcade y sus estados.
- `masks/`: máscaras de interacción, con el mismo tamaño y origen que su fondo.

Conservar el lienzo transparente completo al exportar, sin recortar los bordes.
Para el mini menú: Cook `#00FF00`, Arcade `#0000FF`, cerrar `#FF00FF`.
Los items reutilizan los PNG existentes del inventario; no hace falta duplicarlos.
